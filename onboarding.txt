JR AutoRAG – 5 Minute Onboarding
================================

Follow these steps from a fresh clone to your first answered query.

0) Prerequisites
   - Bun v1.3+, Python 3.11+ with pip
   - OCR deps (for scanned PDFs):
     - macOS: `brew install tesseract poppler`
     - Ubuntu/Debian: `sudo apt-get install tesseract-ocr poppler-utils`
     - Fedora: `sudo dnf install tesseract poppler-utils`

1) Clone & install
   - `git clone <repo> && cd JR-AutoRAG`
   - `bun install`
   - `cd api && python3 -m pip install -r requirements.txt && cd ..`

2) Start everything (recommended)
   - `bun run dev:all`
   - Frontend: http://localhost:3000
   - API: http://localhost:8000

   Manual control (if preferred):
   - API: `cd api && PYTHONPATH=. uvicorn app.main:app --reload --port 8000`
   - UI: `bun dev`

3) Verify connectivity
   - In the UI header, click **Test** next to API Base URL → expect “API reachable”.
   - Optional: `curl http://localhost:8000/healthz`

4) Configure providers
   - Start Ollama (`ollama serve`) or LM Studio.
   - In **Detected Local Providers**, choose **Use Ollama** (or LM Studio) to auto-fill planner/gatherer/generator.
   - Click **Save Configuration**. Rerun **Rescan** if not detected.

5) Ingest a document
   - Drag a PDF/DOCX/Markdown/TXT file into the drop zone (scans auto-OCR).
   - Or use **Ingest Text** for a quick snippet.
   - Confirm the document card shows filename, time, and size.
   - If a PDF shows “no text found,” ensure `poppler` + `tesseract` are installed, then restart the API.

6) Ask your first question
   - Prompt: “What is JR AutoRAG?”
   - Review the answer plus evidence; open **Evaluation & Monitoring** to inspect the trace.

7) Tweak & iterate
   - Switch retrieval preset (Fast / Balanced / Thorough) from the UI.
   - Save provider profiles (local vs cloud) for fast swapping.
   - Remove a document card to rebuild the index if you need a clean slate.

Ready for demos.
